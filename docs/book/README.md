# Libro de IA Agéntica aplicada a ingeniería de software

Este libro desarrolla en profundidad las trece semanas del plan. Cada capítulo está diseñado para estudiarse durante una semana junto con la rutina de [`curso-90-dias.md`](../curso-90-dias.md), el [banco bilingüe](../autoevaluacion.md) y los [ejercicios guiados](../examples/README.md).

## Cómo estudiar cada capítulo

1. **Antes de leer (5–10 min):** responde las preguntas de recuerdo activo al inicio sin apuntes. Escribe tus dudas.
2. **Estudio (25–40 min):** lee conceptos y ejemplo; intenta dibujar el flujo con tus propias palabras.
3. **Práctica deliberada (45–90 min):** realiza el ejercicio sin copiar la solución; conserva entradas, salidas y fallos.
4. **Feynman (5–10 min):** explica el tema a alguien no especialista usando una analogía, un ejemplo y una limitación.
5. **Repaso espaciado:** vuelve a las preguntas al día siguiente y a los 3, 7, 14 y 30 días. Marca errores y su causa, no solo el porcentaje.

Todos los ejemplos usan un producto ficticio, **Shop**, y tickets `SHOP-*`. No conectes los ejercicios a Jira, Git o producción reales: empieza con datos sintéticos y herramientas mock.

## Criterio general de dominio

No consideres dominado un tema solo por reconocer sus términos. Debes poder (a) explicarlo de memoria, (b) implementarlo o modelarlo, (c) demostrar un caso fallido y su recuperación, y (d) justificar qué riesgos siguen requiriendo control humano.
